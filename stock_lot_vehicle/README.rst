Stock Lot Vehicle
==================

El serial de chasis es el nombre del lote. El módulo añade el serial de motor y enlaza la matrícula como otro lote.

Use Cases / Context
-------------------

El serial de chasis ya es el nombre del lote. El motor se anota en el mismo lote y la matrícula se gestiona como un lote propio.

Usage
-----

#. Crea el lote del vehículo. Su nombre es el serial de chasis.
#. Completa Serial de motor.
#. Crea el lote de la matrícula. Su nombre es el número de matrícula.
#. En Matrícula elige ese lote.
