Stock Lot Vehicle
==================

El serial de chasis es el nombre del lote. Si el producto es de vehículo, el serial de motor es obligatorio al crear o elegir el lote. La matrícula es otro lote.

Use Cases / Context
-------------------

El serial de chasis ya es el nombre del lote. El motor se anota en el mismo lote y la matrícula se gestiona como un lote propio.

Usage
-----

#. En el producto marca Producto de vehículo. El producto debe tener seguimiento por lote o serie.
#. Al crear o elegir el serial, completa Serial de motor. Es obligatorio.
#. El nombre del lote es el serial de chasis.
#. Crea el lote de la matrícula con un producto que no sea de vehículo. Su nombre es el número de matrícula.
#. En Matrícula elige ese lote.
